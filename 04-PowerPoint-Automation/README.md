# PowerPoint Automation

## Purpose
Creates `OfficePresentation.pptx` with a title slide and content generated through UiPath Presentations activities.

## Run
Open `project.json`, restore `UiPath.Presentations.Activities`, set `in_OutputFolder` to `Output`, and run `PowerPointAutomation.xaml`.

## Status
Static file validation only; runtime execution still required in UiPath Studio.
