# Excel Automation

## Purpose
Creates or updates `OfficeData.xlsx` with a DataTable through UiPath Excel activities. This is the reusable data source for the integrated project.

## Run
Open `project.json`, restore `UiPath.Excel.Activities`, set `in_OutputFolder` to `Output`, and run `ExcelAutomation.xaml`.

## Status
Static file validation only; runtime execution still required in UiPath Studio.
